# 声音

本机 GPU 一次只跑一个模型，渲染时不跑模型。Python 环境和命令见 `models.md`。每样东西只生成一版直接用，真出问题才重做。

## 配音

- 整段稿子一次生成、一个种子（`tts_clone.py`，参考音和逐字稿见 `models.md`）。这样语气连贯，英文词的读音也稳。
- Breeze 一段超过约 110 秒会悄悄截掉结尾。稿子超过约 550 个中文字时，在章节交界处切成两段，同一条命令、同一种子生成，裁掉首尾静音后隔 0.55 秒拼成一条。
- 拆段生成的后半段语气常和前半段对不上，用户能听出来。没超过 550 字就整段一次生成，不要为了保险提前拆。
- 改个别读音时，把读法直接写进整段文本重新生成（如 tmux → T谬X、2x → 二乘），字幕仍用原文；只补一句再拼回去容易让那一句语气突兀。
- 生成后用 ASR 看最后一句，缺了就单独补那一句再拼回去。只有真读错才重做，同音字不算。
- 英文稿也可以用中文参考音来克隆。

## 对齐

`python <skill>/scripts/audio/align.py vo_full.wav lines.json vo.json`

- `lines.json` 格式：`[{"id", "text"}]`。
- 输出每句的起止时间（`abs`）和每个字的起点（`chars`）。
- 稿子有中文时按中文识别（英文词会作为提示词）；纯英文稿按英文识别。
- `cer` 应该接近 0；偏高时先看 ASR 原文。
- 幕与幕之间要停顿时，在最安静的地方把配音切开，把后面的部分整体往后挪。

## 音效（每期现做，包括转场音）

1. 每个画面事件写成**什么东西碰到什么东西**：转轮停 = 机械咔哒，拍照 = 快门，外卖 = 纸袋窸窣。转场音按这期的转场画面来写：钻进转轮 = 转轮加速的呼呼声，幕布拉开 = 丝绒布料滑过。轻松的片子用轻、亮、短的声音。
2. 写成 `sfx.json`，名字加这期的前缀，转场音用 `tr_` 前缀。提示词末尾加 `isolated`，轻的声音加 `no low boom`，时长 ≥ 1 秒。一次跑完：
   `envs/mmaudio/python.exe <skill>/scripts/audio/gen_sfx.py --spec sfx.json --out sfx --variants 1`（约 6 秒一个）
3. 生成出来不像、或材质对不上的事件，就不配音效。
4. 每个音效的时间点和画面动作用同一个时间，声音跟着画面事件走。

音量：
- 全片每分钟 ≤ 24 个音效，同一个声音 ≤ 4 次。
- 重击全片 ≤ 2 次、gain ≤ 0.5；小东西落地 gain 0.25–0.4。
- `mix.py` 会把每个音效拉到同样的峰值，低频重的声音听起来会更重。

混音前跑 `python <skill>/scripts/audio/sfxcheck.py`（在工程根目录跑，读 `audio/plan.json`）。它会检查这几项：
- 同一个声音的次数和整体音效密度有没有超标；
- 低频是不是太闷（< 150 Hz 的能量占比 > 40%，或重心 < 200 Hz）。

用户点名哪一秒难听，就把这个音效连同它在片中的其他用法一起去掉。

## BGM

每期按这期的调子现生成，只生成 ≤ 100 秒、1 个种子，跑了 10 分钟还没出就停掉。不够长就用 ffmpeg 首尾交叉拼接：`[0]atrim=0:68[a];[a][1]acrossfade=d=3`。生成前先请用户停掉占显存的服务。

## 混音

用 `<skill>/scripts/audio/mix.py --plan plan.json --out mix.wav`：配音、音效（`cues`：名字、时间、gain）、BGM 合在一起，配音出现时 BGM 自动压低，最后归一到 -14 LUFS。plan 的格式见 `mix.py` 文件开头的注释。

混完跑 `python <skill>/scripts/audio/peaks.py mix.wav`：最响的时刻如果落在音效上，就降它的 gain；落在配音的重读上就不用管。

要出 1.25 倍版时，只用 `atempo` 加速配音，时间轴整体除以 1.25，BGM 不变，然后重新混音、重新渲染。
