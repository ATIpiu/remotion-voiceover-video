# 封面和发布文案

成片定稿后做，顺序固定：**钩子卡 → 封面 → 标题 → 正文 → 扫描 → 交付**。观众先看封面、再看标题、再回头看封面确认，封面不抓人，标题就没人看，所以先做封面。

```
- [ ] 1 钩子卡（一句话 + 搜索词）
- [ ] 2 封面：每个版式一张（Codex 生图，片子截图当参考）→ 检查 → 只重做有问题的那张
- [ ] 3 各平台标题 + 正文
- [ ] 4 扫描（AI 味、限流词、事实）
- [ ] 5 交付 publish.md + 封面图
```

## 1 钩子卡

写封面和文案前，先在 `publish.md` 顶部写三行，后面所有东西都从这里出：

- **钩子**：一句话说清"谁、卡在哪个痛点或好奇上、看完能得到什么"。直接沿用片子开头那个问题，封面、标题、片头说的是同一件事，观众点进来才不会觉得被骗。
- **画面**：这期贯穿全片的那个比喻里，最能代表钩子的一个瞬间。
- **搜索词**：观众会在抖音、小红书、B站搜框里打的 2–4 个词（"外卖 抽成""奶茶 成本"）。标题前半段和正文第一句要出现它们。

## 2 封面

用 Codex 生图做（优先用 Codex 的 native-cover-design 技能，见下面「怎么做」），**一个版式只出一张**：这期要发哪些平台，就出哪几个尺寸，每个尺寸用最适合它的版式。不出多套候选让用户挑。

### 先想清楚再写提示词

每张封面动笔前，在钩子卡下面写三行。答案每期按内容自己定，没有固定配方：

- **认什么**：观众扫一眼必须认出来的东西，通常是这期的主题或搜索词（一个名字、产品、事件、数字）。它要在缩略图里读得清。
- **做了什么**：用一句大白话写出这期的主题对象和它的结果（「XX 自动做 YY」「XX 一年涨了多少」），封面主标题就从这句来。
- **为什么点**：让人想点开的那一下。可以是一种情绪、一个反差、一个数字、一个没说完的问题、一个好看的画面，选这期最强的那个。
- **焦点**：承载上面两样的那一个视觉主体。可以是人、物件、数字、对比、场景，也可以只是字，按内容选最能说明问题的。一张封面只有一个焦点，眯眼看，第一眼落在哪里就是焦点。

除了焦点和封面字，最多再加 1–2 个抓眼元素（强对比色、红圈或箭头、主体周围一圈小元素）。再多在手机上就糊了。

### 原则

- **陌生人 3 秒看懂**：没看过片子的人只看封面，也要能说出"这是个做什么的东西、做出了什么"。主标题必须带主题对象和结果。只放情绪、反差或比喻的字（「一个周末 → 一分钟」「稿子进去，视频出来」）只有看过片子的人才懂，信息流里没人点。比喻可以留在画面里，也可以当小字，主标题要说人话。
- **画出结果**：画面里要看得到这期的产出或变化本身（输入 → 产出、之前 → 之后），比如一页稿子变成一个带播放键的视频画面。片子里的比喻世界只当画风和场景，不当唯一的信息。
- **封面字和标题互补**：标题讲"这期讲什么"，封面讲"看完什么感受"，或者戳痛点、亮结果。同一句话不要两处都写；封面上不放叙事长句。
- **引用先弄懂再画**：封面用到梗、名言、典故、流行语时，先查清它原本的意思和画面，按原意表现，别按字面联想。
- **认得出**：画面里出现具体的人、产品、地点，就要让人认得出是谁、是什么。涉及真实人物的形象，先问用户怎么处理（是否用、用什么形式）。
- **参考图**：给 Codex 的参考用干净的素材（透明底物件、无字幕的画面），说清楚参考的是画风和元素，构图按这张封面重新排。带字幕的成片截图会被照搬，主体偏小、字糊。
- **曝光和颜色**：提示词写明曝光正常（高光不发白、暗部有细节），颜色和片子一致。
- **焦点够大**：焦点在缩略图里要看得清；提示词里直接写它占画面的比例。
- **口径不超过片子**：片子里是"疑似""网友称"，封面字也得保留这层意思，或者不写判断句。
- **以片子为依据**：同一个画风、同一批角色和物件，观众点进来看到的和封面一致。信息流里渐变科技风的精致海报像广告。

### 版式和尺寸

先问用户这期发哪些平台（没说就按片子方向：竖屏出 9:16 + 3:4，横屏出 4:3 + 16:9 + 3:4）。每个尺寸的版式：

| 尺寸 | 用在 | 版式 | 封面字 | 安全区 |
|---|---|---|---|---|
| 9:16 1080×1920 | 抖音 / TikTok / Reels / Shorts 视频封面 | **反差款**：一句反常识的话 + 一个主体，主体和字上下叠在中段 | 1–2 行，每行 ≤ 8 字 | 顶部约 230 px、底部约 420 px、右侧约 140 px 被界面盖住 |
| 3:4 1080×1440 | 小红书、抖音信息流、主页网格 | **主体款**：一个主体（人、物、数字或画面）居中占大头 | 1–2 行，每行 ≤ 8 字 | 左右 72–96 px，上 72–112 px，下 80–120 px |
| 4:3 1200×900 / 1440×1080 | B站投稿和手机首页、横版信息流 | **结果款**或**对比款**：左边输入、右边产出，或前后、A vs B；两边都和主题直接相关 | 主标题一行 ≤ 14 字放上部（主题对象 + 结果），可加一行小字 | 左下角是时长角标 |
| 16:9 1920×1080 | B站电脑端 / YouTube | **结果款**、**对比款**，或主体偏一侧、字放另一侧 | 主标题一行 ≤ 14 字（主题对象 + 结果），可加一行小字 | B站左下、YouTube 右下是时长角标 |

同一期各版式的封面字可以不一样，但说的是同一个钩子。

### 封面字

- 很小的位置（头像旁、方形缩略）另写 4–10 字的短标题。提炼法：找出**核心动词 + 核心对象**，删掉修饰和"如何/为什么"。「开源了一个 Skill，让 AI 接管你屏幕边那张便签纸」→「AI 接管便签纸」。
- 三行以上就是太长了，删字，不要缩字号。
- 数字是新闻点时数字打头、字最大：「↓3.4kg 装备减重」。
- 只突出一个关键词（色块、下划线或换色），在提示词里写明哪个词怎么突出。
- 断行自己定，在 `text` 里用换行写好，不交给 Codex 自动换行。

### 怎么做

1. 准备参考图：按这张封面的焦点挑，片子里用的素材（透明底物件、角色图）或无字幕的画面（`npx remotion still`，或渲染时关掉字幕）。
2. **装了 Codex 的 native-cover-design 技能时（优先）**：整张封面（画面、版式、字）都由 ImageGen 一次生成，不在本地叠字、拼图、缩放。每个版式写一条进 `covers.json`，`_about` 写这期讲什么、产出是什么：

```json
{
  "_about": "这期视频讲什么、做出了什么（一两句）",
  "cover_4x3": {
    "platform": "B站投稿封面（横版 4:3）", "ratio": "4:3", "size": "1440×1080",
    "ref": ["refs/a.png"],
    "layout": "版式与层级：焦点是什么、放哪、占多大；主标题在哪、突出哪个词；画面怎么表现输入 → 产出",
    "text": ["主标题（主题对象 + 结果）", "小字"],
    "safe": "左下角约 18%×11% 是时长角标"
  }
}
```

   跑 `node <skill>/scripts/codex_cover.mjs covers.json covers`。它一张一张跑：并发时 Codex 可能把别的任务生成的图存成这张。每张约 3–14 分钟，出来的尺寸接近目标比例，不保证像素精确，不要本地缩放。
3. **没装这个技能时**：每个版式写一条 `cover` 条目进 `covers.json`：

```json
{
  "cover_9x16": {
    "cover": true, "size": [1080, 1920], "ref": ["refs/a.png", "refs/b.png"],
    "prompt": "{版式}。焦点是{这期选的主体}，放在{位置}、占画面{比例}；封面字{位置和大小}，突出{哪个词、怎么突出}；画风和颜色同参考图，曝光正常……",
    "safe": "顶部 230 px、底部 420 px、右侧 140 px 不放字和脸",
    "text": {"大字": "……", "小字": "……"}
  }
}
```

   跑 `node <skill>/scripts/codex_images.mjs covers.json covers --jobs 1`。
4. 逐张检查（见下）。哪张有问题，只重做那一张（`--only cover_4x3`）；要在原图上小改时，`ref` 改成这张封面自己，写清"只改 XX，其余保持不变"。

### 封面自检

- **3 秒测试**：假装没看过片子，只看 3 秒，能说出"这期讲的是什么、做出了什么"和"为什么想点"。说不出来，回到"先想清楚"那几行；最常见的原因是主标题只有比喻或情绪，没有主题对象。
- **认得出**：画面里的人、物、引用都认得出、没画错意思。
- **字**：和 `text` 一字不差，没有错别字、乱码、多出来的字。Codex 中文偶尔写错，这一项必看。
- **尺寸**：像素和表里一致，主体和字没被裁掉。
- **安全区**：字和脸不在被盖住的区域里。
- **缩小看**：缩到信息流大小（横屏约 320×180，竖屏约手机屏的 1/16），字读得出、主体认得出。
- **跳不跳**：和两三个同题材热门视频的封面并排，颜色撞了就换。

## 3 标题和正文

### 标题

- 每个平台 3–5 个备选，风格各不一样：痛点、提问、反差、数字、身份、热点。
- 搜索词放在前 10 个字里，信息流截断和搜索都看前面。
- 和片子内容一致，承诺多少就兑现多少。

句式参考（换成这期的内容）：

| 句式 | 骨架 |
|---|---|
| 痛点 + 答案 | {具体痛点}？{一句话结论或悬念} |
| 提问 | 有没有人算过/想过 {具体问题} |
| 反差 | 我以为是 {常见看法}，结果是 {真相的一半} |
| 数字 | {具体数字} + {出人意料的对比} |
| 身份 | {人群}在 {场景} 前，先看这 {N} 分钟 |
| 热点 | {热点}之后，我把 {对象} 拆开看了看 |

### 正文

结构是**钩子 → 干货 → 互动**：

- **第一句**就戳痛点或抛结论，带上搜索词，不铺垫。
- **中间**只讲这期最独特的 1–2 个点，别把片子复述一遍。第一人称，像跟朋友说话，手机上每段不超过 3 行。
- **结尾**抛一个具体、好回答的问题。"你们觉得呢"太泛，"你最近一单外卖多少钱"才有人回。评论和关注对推荐的作用比点赞大。
- 数据和事实只用片子里有的，缺了就问用户，不编。

### 各平台

| 平台 | 标题 | 正文 | 标签 | 另外 |
|---|---|---|---|---|
| B站 | ≤ 80 字，可带"｜A vs B" | 一句话概括 + 章节时间戳（按实际发布的倍速算）+ 资料来源 | 10 个 | 分区；置顶评论补充片子里没讲的一个点 |
| 小红书 | ≤ 20 字 | 300–800 字大白话，1️⃣–5️⃣ 分段，emoji 只当段落标记 | 5–10 个 | 封面字可以比标题更口语 |
| 抖音 | ≤ 30 字 | 两句话描述 | 5–6 个 | 置顶评论抛问题引讨论 |
| TikTok（英文） | 一句钩子，≤ 100 字符 | 2–4 行，口语、短句 | 6–8 个 | 置顶评论；封面字用英文重写，别直译 |

- 标签：2–3 个大词（#科普 #涨知识）+ 这期主题的具体词，具体词比大词有用。
- TikTok 英文：用 you 跟观众说话，钩子用问题或反常识的事实（"Your $5 coffee is mostly rent."），避免 "In this video…""Let's dive in"。

## 4 发出前扫描

标题、封面字、正文都扫，标题最严。命中就改；为了过规则把句子改僵了，就保留原样。

**AI 味**（一看就是 AI 写的）：
- 词：说白了、本质上、换句话说、值得注意的是、不难发现、综上所述、总的来说、让我们来看看、赋能、底层逻辑、抓手、赛道。英文：delve、game-changer、unlock、in today's fast-paced world。
- 结构：首先…其次…最后；"在当今……的时代"开头；"希望对你有帮助"结尾；加粗小标题；用破折号解释。

**会被限流**：
- 极限词（广告法）：最、第一、唯一、独家、首个、顶级、极致、绝对、100%、保证、史上。改成"我用过最顺手的之一""我自己试下来有效"。
- 站外导流：微信、vx、二维码、公众号、私我、联系方式。站内说"评论区见""私信我"可以。
- 收益承诺：月入过万、躺赚、稳赚、零风险。真实发生过的数据可以写，别写成对观众的承诺。
- 营销黑话：引流、私域、割韭菜、起号、刷量。
- 敏感时政：观点可以留，降低识别度，并提醒用户这类内容流量上限低。

小红书不公开违禁词库，网上的"大全"不可信。被限流后，把实际命中的词补进上面对应的类别，标上日期。

**事实**：标题和正文里每个数字、每个结论都能在片子里找到出处。

## 5 交付

成片、封面、文案复制进同一个交付文件夹（如 `<这期>/交付/`），里面只放这些：`成片.mp4`、`封面_16x9.png` 等（文件名写清尺寸）、`发布文案.md`。工程、素材、中间版本都留在原处，最后把文件夹路径告诉用户。

`发布文案.md` 按这个顺序，每段都能直接复制：

```
# {这期主题}
钩子：…　画面：…　搜索词：…

## 封面
文件：cover_9x16.png、cover_3x4.png …（每张对应哪个平台）

## B站
标题备选 1–5 / 简介（含时间戳）/ 标签 / 分区 / 置顶评论

## 小红书
标题备选 / 正文 / 话题

## 抖音
标题备选 / 描述 / 话题 / 置顶评论

## TikTok
Hook options / Caption / Hashtags / Pinned comment
```

最后提醒用户：
- 勾选"AI 生成内容"（配音是克隆的声音，素材是 AI 生成的）。
- 公开提到雇主时，先确认公司的对外发言规定。
- 配音和 BGM 只能非商用，接商单前要换成可商用的素材。
